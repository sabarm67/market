# Share Market Monitoring & Investment Intelligence Platform

An AI-assisted investment intelligence platform for Bursa Malaysia, designed as Phase 1 of a
longer-term "Bloomberg Terminal for individual investors" vision.

## Status

**Current phase: Documentation.** No application code exists yet. This repository currently
contains only planning and design documentation under [`docs/`](docs/README.md).

## Scope of This Phase (MVP)

- **Market:** Bursa Malaysia (Main Market, ACE Market, LEAP Market) only.
- **Modules:** Market Dashboard, Company Profile, Fundamental Analysis, Basic Technical
  Analysis, Watchlist, Shariah Compliance.
- Everything beyond this (other markets, AI recommendation engine, news intelligence,
  screener, portfolio management, alert engine, RAG research assistant, advanced charting)
  is captured as a future roadmap item — see
  [`docs/07-roadmap/future-enhancements-roadmap.md`](docs/07-roadmap/future-enhancements-roadmap.md).
