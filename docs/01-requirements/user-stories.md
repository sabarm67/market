# User Stories

Format: *As a [role], I want [capability], so that [benefit].* Grouped by epic, mapped to
[Use Cases](use-cases.md).

## Epic: Market Dashboard (UC-1)

- As a Guest, I want to see today's top gainers/losers/volume for Bursa Malaysia, so that
  I can quickly spot notable market activity without logging in.
- As a Registered Investor, I want to filter the dashboard by sub-market and sector, so
  that I can focus on the segment I care about.

## Epic: Company Profile (UC-2)

- As a Guest, I want to search for a company by name or stock code, so that I can quickly
  find the security I'm researching.
- As a Registered Investor, I want to see a company's management and major shareholders,
  so that I understand who controls and runs the business.

## Epic: Fundamental Analysis (UC-3)

- As a Registered Investor, I want to see a company's key ratios (PE, ROE, margins,
  dividend yield), so that I can assess its financial health at a glance.
- As a Registered Investor, I want to see 3+ years of historical fundamentals, so that I
  can judge whether performance is improving or deteriorating.

## Epic: Basic Technical Analysis (UC-4)

- As a Registered Investor, I want to view a candlestick chart with moving averages and
  RSI, so that I can assess price trend and momentum.
- As a Registered Investor, I want to switch chart timeframes, so that I can view both
  short-term and longer-term price action.

## Epic: Watchlist (UC-5)

- As a Registered Investor, I want to create multiple watchlists, so that I can organize
  securities by theme or strategy.
- As a Registered Investor, I want to see Shariah status directly in my watchlist, so that
  I don't have to check each company individually.
- As a Registered Investor, I want to add a note to a watchlist item, so that I can
  remember why I'm tracking it.

## Epic: Shariah Compliance (UC-6, UC-7)

- As a Shariah-conscious investor, I want to see a company's current Shariah status and
  the date it was determined, so that I can trust how current the information is.
- As a Shariah-conscious investor, I want to browse all Shariah-compliant Bursa securities
  in one screen, so that I can build a compliant shortlist.
- As an Admin, I want to import the latest SC Malaysia Shariah list and preview the
  changes before committing, so that I can update the platform accurately after each
  biannual publication.

## Epic: Account (UC-8)

- As a Guest, I want to register with email/password, so that I can save watchlists.
- As a Registered Investor, I want to log in securely, so that my watchlists are private
  to me.
